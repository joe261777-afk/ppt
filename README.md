# Workshop Evaluation Generator — Streamlit Cloud

## Deployment

1. Extract this ZIP and upload all files (including `templates/` with both PPTX files) to the **root** of your GitHub repository.
2. Open https://share.streamlit.io/ and click **Create app**.
3. Select the repo and branch `main`, set the main file path to `app.py`, then deploy.
4. Streamlit Cloud will install `requirements.txt` and `packages.txt`. The app does **not** need Google Colab or Google Drive.

## Inputs

- Survey results PDF
- Survey responses Excel
- Attendance Excel or image (OCR requires manual confirmation)

## Security

Keep your application private when processing participants' personal data and signatures. Uploaded files are processed by the selected hosting provider.
